# 界面多语言（i18n）

> 0.7.0 起界面支持简体中文 / Français 切换。本文给继续开发的人看，说明文案该怎么写、语言怎么切换。

## 1. 结构

```
src/i18n/
├─ index.js            主进程与 preload 共用的核心：supported / getLang / setLang / t / catalog
├─ fr.json             法语词典（key → 法语）
└─ manual-anchors.json 手册章节的稳定 ASCII 锚点（phase 5 用）
src/ui/i18n-dom.js     渲染层脚本：按 data-i18n* 属性把静态 HTML 翻成当前语言
src/core/store.js      uiLanguage 设置项（默认 zh-CN；持久化在 settings.json）
src/preload.js         把 i18n 的 t/setLang/getLang 暴露给渲染层
src/main.js            托盘菜单、窗口 lang 属性跟随界面语言
```

## 2. 核心约定

- `t(key, defaultZh, params)`：**第二个参数必须传原文中文**。当语言是 `zh-CN`、或 `fr.json` 缺 key 时，会原样返回这个中文（零回归）。
- `params` 用 `{name}` 占位符：`t('tray.closeAppNamed', '关闭当前应用（{name}）', { name })`。
- 不翻译：标识符、JSON 键名、命令、路径、URL、包名、日志信息、代码注释。
- `engine.locale` 是**安卓系统内部语言**（进虚拟机），与 `uiLanguage`（界面语言）是两回事，不要混用。

## 3. 静态 HTML 文案

给元素加属性，脚本会在页面加载时替换，并记住原文，切回中文时恢复：

```html
<span data-i18n="settings.title">设置</span>
<button data-i18n-title="tray.manual" title="使用手册">…</button>
<input data-i18n-placeholder="settings.search" placeholder="搜索设置项…" />
```

现有阶段只覆盖了少量演示字段；界面文案的全面接入在后续阶段完成。

## 4. 动态文案

toast / 对话框 / 菜单等用 JS 生成的地方，直接调用：

```js
const api = window.apkstart;
toast({ title: api.i18n.t('settings.uiLanguage.changedTitle', '界面语言已更新') });
```

主进程同理：

```js
const i18n = require('./i18n');
menuLabel = i18n.t('tray.open', '打开 ApkStart');
```

## 5. 切换流程

1. 设置 → 常用与安装 → 界面语言，选 Français；
2. `api.setSettings({ uiLanguage: 'fr' })` 写盘；
3. main 进程的 `settings:set` 更新内存语言并重建托盘菜单；
4. 渲染层 `api.i18n.setLang('fr')` + `I18nDom.apply(document)` 立即替换 DOM。

## 6. 新增文案的检查清单

- [ ] 中文默认值写进 `t()` 的第二个参数；
- [ ] `fr.json` 补上同 key 的法语；
- [ ] 长文案检查法语会不会撑破按钮 / 卡片（法语通常比中文长 15–30%）；
- [ ] `node --check` 与 `npm test` 通过。
